Part 1

8085 & 8086 Microprocessor Architecture (Direct TPSC PYQ Focus)

10 One-Liners
  • ⚡[TPSC PYQ 2025] Intel 8085 is an 8-bit microprocessor with an 8-bit data bus and a 16-bit address bus (can address 2^16 = 64 KB of memory).
  • ⚡[TPSC PYQ 2025] Intel 8086 is a 16-bit microprocessor with a 16-bit data bus and a 20-bit address bus (can address 2^20 = 1 MB of memory).
  • ⚡[TPSC PYQ 2025] In 8085, the Accumulator (8-bit register A) stores one of the operands and the result of arithmetic and logical operations.
  • ⚡[TPSC PYQ 2025] Program Counter (PC) in 8085 is a 16-bit special-purpose register that holds the memory address of the NEXT instruction to be fetched.
  • ⚡[TPSC PYQ 2025] Stack Pointer (SP) in 8085 is a 16-bit register that always points to the top of the stack in memory (stack grows downward).
  • ⚡[TPSC PYQ 2025] Memory Address Register (MAR / Address Register) holds the address of the memory location currently accessed for data transfer.
  • ⚡[TPSC PYQ 2025] 8085 has 6 general-purpose 8-bit registers (B, C, D, E, H, L) which can form 3 16-bit register pairs (BC, DE, HL), plus 5 Flag bits (Sign S, Zero Z, Auxiliary Carry AC, Parity P, Carry CY).
  • ⚡[TPSC PYQ 2025] 8085 Addressing Modes (5 modes): Immediate (MVI A, 05H), Register (MOV A, B), Direct (LDA 2500H), Register Indirect (MOV A, M via HL pair), and Implied/Implicit (CMA, STC).
  • ⚡[TPSC PYQ 2025] Data transfer instructions in 8085 include MOV, MVI, LDA, STA, LXI, LHLD, SHLD (they do NOT affect any flags!).
  • ⚡8085 Hardware Interrupts (5 pins): TRAP is Non-Maskable and highest priority (vectored to 0024H); RST 7.5, RST 6.5, RST 5.5, and INTR (lowest priority, non-vectored).
Part 2

CPU Organization, Buses, Addressing Modes & Instruction Cycle (TPSC PYQ Focus)

9 One-Liners
  • ⚡[TPSC PYQ 2025] Core components of the CPU are the Arithmetic Logic Unit (ALU), Control Unit (CU), and Registers (Hard Disk Drive is secondary storage, NOT a CPU component).
  • ⚡[TPSC PYQ 2025] A Bus in computer organization is a shared physical pathway (set of wires) for transferring addresses, data, and control signals between components.
  • ⚡[TPSC PYQ 2025] The Control Unit (CU) is responsible for fetching instructions from memory, decoding them, and generating timing/control signals.
  • ⚡[TPSC PYQ 2025] The Arithmetic Logic Unit (ALU) performs all arithmetic (addition, subtraction) and bitwise logical (AND, OR, XOR, shift) operations.
  • ⚡[TPSC PYQ 2024] Parallel processing involves executing multiple tasks or instructions simultaneously across multiple processing units.
  • ⚡Address Bus is unidirectional (CPU -> Memory/IO), Data Bus is bidirectional, and Control Bus carries read/write/interrupt control lines.
  • ⚡Effective Address (EA) in key Addressing Modes: Immediate (no memory ref, fastest), Direct (EA = Address field, 1 mem ref), Indirect (EA = M[Address], 2 mem refs), PC-Relative (EA = PC + Offset, used for relocatable code and branch instructions), Base/Indexed (EA = R_base + Index, used for arrays).
  • ⚡Hardwired Control Unit uses fixed combinational logic (faster, used in RISC), whereas Microprogrammed Control Unit stores control words in Control Memory ROM (flexible, used in CISC).
  • ⚡RISC (Reduced Instruction Set Computer) uses fixed-length instructions, single-cycle execution, load/store architecture, and many registers; CISC uses variable-length complex instructions.
Part 3

Instruction Pipelining & Pipeline Hazards

7 One-Liners
  • ⚡Classic 5-Stage RISC Pipeline: IF (Instruction Fetch) -> ID (Decode & Register Read) -> EX (Execute/ALU) -> MEM (Memory Access) -> WB (Write Back).
  • ⚡Pipeline Clock Period τ = max(stage delays) + latch overhead; execution time for N instructions on a k-stage pipeline is T_pipe = (k + N - 1) × τ.
  • ⚡Ideal Pipeline Speedup as N → ∞ is equal to the number of stages k; with average stall penalty s per instruction, CPI_actual = 1 + s.
  • ⚡Structural Hazard occurs when two instructions in different stages compete for the same hardware resource (solved by separate Instruction and Data caches — Harvard architecture).
  • ⚡Data Hazard (RAW — Read After Write) is a true dependency solved by Operand Forwarding (Bypassing); Load-Use hazard still requires 1 stall bubble.
  • ⚡WAR (Write After Read — Anti-dependency) and WAW (Write After Write — Output dependency) are name dependencies eliminated by Register Renaming.
  • ⚡Control (Branch) Hazard occurs when a conditional branch changes PC; mitigated via Branch Prediction, Delayed Branch (delay slot), and Branch Target Buffer (BTB).
Part 4

Memory Hierarchy, Cache Mapping & I/O Interface (TPSC PYQ Focus)

9 One-Liners
  • ⚡[TPSC PYQ 2025] Access speed order (Fastest to Slowest): CPU Registers > Cache Memory (SRAM) > Main Memory (DRAM) > Solid State Drive (SSD) > Hard Disk Drive (HDD) > Magnetic Tape.
  • ⚡[TPSC PYQ 2024] In Direct Mapping with m main memory blocks and n cache blocks (lines), the Cache Index field requires log_2(n) bits, and the Tag field requires log_2(m/n) bits.
  • ⚡SRAM (Static RAM, 6 transistors per cell, fast, no refresh needed) is used for Cache; DRAM (Dynamic RAM, 1 transistor + 1 capacitor, dense, requires periodic refresh) is used for Main Memory.
  • ⚡Direct Mapping formula: Memory Block B maps strictly to Cache Line (B mod n); suffers from conflict misses (thrashing) but has the simplest tag comparison (1 comparator).
  • ⚡Fully Associative Mapping allows Block B to go into ANY cache line (0 index bits; Address = Tag + Offset); eliminates conflict misses but needs n parallel comparators.
  • ⚡k-Way Set-Associative Mapping has S = n/k sets; Block B maps to Set (B mod S), with Index = log_2(S) bits and k comparators.
  • ⚡Effective Memory Access Time (EMAT): Simultaneous = h·t_c + (1-h)·t_m; Hierarchical = t_c + (1-h)·t_m (where h = hit ratio).
  • ⚡Cache Write Policies: Write-Through updates cache and main memory simultaneously (uses Write Buffer); Write-Back updates only cache and sets a Dirty Bit (writes to memory only on eviction).
  • ⚡DMA (Direct Memory Access) transfers bulk data directly between I/O device and Main Memory without CPU intervention using Bus Mastering (Cycle Stealing or Burst Mode).
