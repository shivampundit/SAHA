Part 1

Cyber Security Principles, Malware, Network Attacks & Defenses (Direct TPSC PYQ Focus)

8 One-Liners
  • ⚡[TPSC PYQ 2025] Cyber Security is best defined as the practice of protecting computer systems, networks, programs, and data from malicious digital attacks, unauthorized access, and damage.
  • ⚡CIA Triad of Information Security: Confidentiality (preventing unauthorized disclosure via Encryption/Access Control), Integrity (preventing unauthorized modification via Hashing/Digital Signatures), and Availability (ensuring timely access via Redundancy/DDoS protection).
  • ⚡[TPSC PYQ 2025] The primary function of a Firewall in a computer network is to monitor and block unauthorized inbound/outbound access and traffic based on security rules.
  • ⚡[TPSC PYQ 2024] A Malware Scanner (Antivirus / EDR) is used to detect, quarantine, protect against, and remove malicious/unwanted programs.
  • ⚡[TPSC PYQ 2025] DDoS (Distributed Denial of Service) is a cyber attack that uses a botnet of multiple compromised devices to flood and overwhelm a target server/network, exhausting its availability.
  • ⚡[TPSC PYQ 2025] Phishing is a social-engineering technique using deceptive emails/websites impersonating trusted entities to trick users into revealing sensitive personal information (passwords, OTPs, credit card details).
  • ⚡Malware Types: Virus (attaches to a host file and requires user execution), Worm (self-replicates across networks automatically without a host file), Trojan Horse (disguised as legitimate software, creates backdoors), Ransomware (encrypts victim files and demands payment), Rootkit (hides deep in OS kernel), Spyware/Keylogger (covertly steals keystrokes).
  • ⚡IDS (Intrusion Detection System) is a passive 'sniff-and-alert' sensor on a SPAN port, whereas IPS (Intrusion Prevention System) sits inline to actively drop malicious packets in real time.
Part 2

Cryptography, Hashing, TLS & OWASP Top 10 Vulnerabilities (Direct TPSC PYQ Focus)

9 One-Liners
  • ⚡[TPSC PYQ 2025] Protecting stored/transmitted data from unauthorized access relies on Symmetric/Asymmetric Encryption (for reversible confidentiality) and Password Hashing (with cryptographic salt for one-way credential storage).
  • ⚡[TPSC PYQ 2024] TLS (Transport Layer Security, successor to SSL) is the cryptographic protocol used to encrypt email (STARTTLS/SMTPS) and web (HTTPS) communications for enhanced security.
  • ⚡Symmetric Encryption (Single shared secret key: AES-128/256, ChaCha20, 3DES) is fast and used for bulk data encryption; Asymmetric Encryption (Public/Private key pair: RSA, ECC, Diffie-Hellman) solves key exchange and provides Digital Signatures.
  • ⚡Digital Signature Process: Sender hashes message `H = SHA256(M)` and encrypts the hash with Sender's PRIVATE Key; Receiver verifies using Sender's PUBLIC Key (guarantees Authentication, Integrity, and Non-Repudiation!).
  • ⚡OWASP Top 10 (2021) #1 Vulnerability is `A01:2021 — Broken Access Control` (IDOR, privilege escalation, missing function-level access control).
  • ⚡OWASP `A03:2021 — Injection` (SQL Injection, OS Command Injection, Cross-Site Scripting XSS): Prevented primarily by Parameterized Queries (Prepared Statements) for SQLi, and Context-Aware Output Encoding + Content Security Policy (CSP) for XSS.
  • ⚡CSRF (Cross-Site Request Forgery) forces an authenticated browser to send forged state-changing requests; mitigated via Anti-CSRF Tokens and `SameSite=Strict/Lax` cookie attributes.
  • ⚡SSRF (Server-Side Request Forgery, `A10:2021`) tricks the backend server into fetching internal URLs (such as cloud instance metadata `http://169.254.169.254/`).
  • ⚡Buffer Overflow in C/C++ occurs when unchecked functions like `gets()`, `strcpy()`, `sprintf()` overwrite the return address on the stack; prevented by bounds-checked functions (`snprintf`, `strncpy`), Stack Canaries, ASLR, and DEP/NX bit.
Part 3

Emerging Technologies: Blockchain, IoT, AI/ML, AR/VR, LiDAR & 5G (Direct TPSC PYQ Focus)

9 One-Liners
  • ⚡[TPSC PYQ 2025] The main advantage of Blockchain technology is that it provides a Decentralized, Immutable, and Tamper-Evident distributed ledger without requiring a central intermediary.
  • ⚡Each block in a Blockchain contains: Block Header (Previous Block SHA-256 Hash, Timestamp, Nonce, Merkle Root of transactions) and Transaction list; Bitcoin uses Proof of Work (PoW), Ethereum uses Proof of Stake (PoS), and Hyperledger uses PBFT/Raft.
  • ⚡[TPSC PYQ 2025] A key feature of Artificial Intelligence (AI) is the automation of cognitive tasks (learning, reasoning, perception, NLP, decision-making) that traditionally require human intelligence.
  • ⚡AI/ML Paradigms: Supervised Learning (labeled data: Regression & Classification — SVM, Random Forest, Neural Nets), Unsupervised Learning (unlabeled data: K-Means Clustering, PCA), and Reinforcement Learning (agent learns via rewards/penalties).
  • ⚡Deep Learning Architectures: CNNs (Convolutional Neural Networks) excel at image/computer vision; RNNs/LSTMs and Transformers (Self-Attention, GPT/BERT LLMs) excel at sequence and Natural Language Processing.
  • ⚡[TPSC PYQ 2025] Virtual Reality (VR) creates a completely immersive simulated digital environment (using headsets), whereas Augmented Reality (AR) overlays digital graphics onto the real physical world.
  • ⚡[TPSC PYQ 2025] LiDAR (Light Detection and Ranging) uses pulsed laser light to measure distances and generate precise 3D point-cloud maps for obstacle detection in Autonomous (Self-Driving) Vehicles.
  • ⚡[TPSC PYQ 2025] 5G technology provides significantly Lower Latency (~1 ms air latency), Higher Data Speeds (up to 10–20 Gbps peak), and Massive IoT device density compared to 4G LTE.
  • ⚡IoT (Internet of Things) Protocols: MQTT (lightweight Publish-Subscribe protocol over TCP via a Broker) and CoAP (Request-Response over UDP for constrained sensors); 6LoWPAN adapts IPv6 over IEEE 802.15.4 low-power wireless meshes.
