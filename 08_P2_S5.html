Part 1

Arrays, Linked Lists, Stacks, Queues & Recursion (Direct TPSC PYQ Focus)

11 One-Liners
  • ⚡[TPSC PYQ 2025] Linear Data Structures: Array, Linked List, Stack, Queue; Non-Linear Data Structures: Tree, Graph.
  • ⚡[TPSC PYQ 2025] Time complexity of accessing an element in an Array by its index is O(1) (Random Access); Space complexity of an array of size n is O(n).
  • ⚡[TPSC PYQ 2024] Linked Lists are NOT suitable for Binary Search (requires O(n) traversal because random access is absent), whereas Insertion Sort, Radix Sort, and Polynomial Manipulation work well on linked lists.
  • ⚡[TPSC PYQ 2024] Time complexity to count the number of elements in a singly linked list of n nodes is O(n).
  • ⚡[TPSC PYQ 2025] In a Doubly Linked List, each node contains 3 fields: Data, a pointer to the next node, and a pointer to the previous node.
  • ⚡[TPSC PYQ 2025] Stack follows LIFO (Last-In, First-Out); allowed operations are Push, Pop, and Peek/Top (Deleting an element from the middle is NOT directly possible in a Stack).
  • ⚡[TPSC PYQ 2025] Stack is the data structure used for the implementation of Recursion (via the system call stack / activation records), expression evaluation, and function calls.
  • ⚡[TPSC PYQ 2025] Queue follows FIFO (First-In, First-Out); in a Circular Queue, the last position is connected back to the first position (front/rear increment modulo N) to prevent false overflow.
  • ⚡Row-Major Address of A[i][j] (0-indexed, R×C, element size w): Base + (i·C + j)·w; Column-Major Address: Base + (j·R + i)·w.
  • ⚡Number of stacks needed to implement a Queue is 2; Number of queues needed to implement a Stack is 2.
  • ⚡Prefix (Polish) and Postfix (Reverse Polish) notations do NOT require parentheses and can be evaluated in O(n) time using a single Stack.
Part 2

Trees, Binary Search Trees (BST), AVL Trees, Heaps & Graphs (TPSC PYQ Focus)

10 One-Liners
  • ⚡[TPSC PYQ 2025] In any tree (including a binary tree) with n nodes, the number of edges is always (n - 1).
  • ⚡[TPSC PYQ 2025] Worst-case time complexity for searching an element in a Binary Search Tree (BST) is O(n) (occurs when the BST degenerates into a left- or right-skewed tree); average/balanced case is O(log n).
  • ⚡[TPSC PYQ 2025] Valid types of Binary Trees include Complete Binary Tree, Full/Strict Binary Tree, Balanced (AVL) Binary Tree, and Skewed Binary Tree ('Circular Binary Tree' is NOT a valid binary tree type).
  • ⚡Degree-0 vs Degree-2 Node Theorem in Binary Tree: Number of leaf nodes L = n_0 is always 1 more than the number of internal nodes with two children: n_0 = n_2 + 1.
  • ⚡Maximum nodes at level i (root at level 0) = 2^i; Maximum total nodes in a binary tree of height h = 2^(h+1) - 1.
  • ⚡Inorder traversal (Left-Root-Right) of any Binary Search Tree (BST) always produces elements in sorted ascending order.
  • ⚡Unique Binary Tree Reconstruction requires Inorder + Preorder OR Inorder + Postorder (Preorder + Postorder alone CANNOT uniquely reconstruct a general binary tree, unless it is a Full binary tree).
  • ⚡AVL Tree is a height-balanced BST where Balance Factor |h_L - h_R| ≤ 1 for every node; uses 4 rotations (LL, RR, LR, RL) and guarantees O(log n) search, insert, and delete in the worst case.
  • ⚡Binary Heap is a Complete Binary Tree stored in an array: Find-Max/Min = O(1), Insert = O(log n), Extract-Max/Min = O(log n), and Bottom-Up Build-Heap (Floyd's algorithm) = O(n)!
  • ⚡Graph Representations: Adjacency Matrix uses Θ(V²) space (O(1) edge check); Adjacency List uses Θ(V + E) space; Handshaking Lemma: Σ deg(v) = 2|E|.
Part 3

Programming in C, C++ & Java (Direct TPSC PYQ Focus)

13 One-Liners
  • ⚡[TPSC PYQ 2024] In C, primitive data types are int, char, float, double, void ('string' is NOT a built-in primitive keyword in C; strings are null-terminated char arrays).
  • ⚡[TPSC PYQ 2024] A Function Prototype in C is used to declare a function (its name, return type, and parameter types) before its actual definition so the compiler can perform type checking.
  • ⚡[TPSC PYQ 2024] 'typedef' in C is used to define a new alias/data type name based on an existing data type (e.g., typedef struct Node Node;).
  • ⚡[TPSC PYQ 2024] In C, passing pointer pi = &i to scanf('%d', pi) reads an integer into i, and printf('%d', i+5) prints 5 more than the integer entered.
  • ⚡[TPSC PYQ 2024] A 'static' local variable inside a C recursive function retains its value across all recursive calls and is initialized only once in the Data/BSS segment.
  • ⚡[TPSC PYQ 2025] Core pillars of Object-Oriented Programming (OOP) are Encapsulation, Abstraction, Inheritance, and Polymorphism ('Compilation' is NOT an OOP feature).
  • ⚡[TPSC PYQ 2025] In C++, the arrow operator '->' accesses class/struct members through a pointer (ptr->x is equivalent to (*ptr).x), while '.' accesses via an object and '::' is Scope Resolution.
  • ⚡[TPSC PYQ 2025] Constructors in C++/Java have the exact same name as the class (`ClassName() {}`), have NO return type (not even void), and are called automatically when an object is created.
  • ⚡[TPSC PYQ 2025] In C++, the 'delete' operator frees dynamically allocated heap memory (allocated via 'new'); in C, 'malloc/calloc' pairs with 'free()'.
  • ⚡[TPSC PYQ 2025] In Java, object creation syntax is `Person obj = new Person();`; class inheritance uses the keyword `extends` (interfaces use `implements`).
  • ⚡[TPSC PYQ 2025] In Java, the `super` keyword refers to the immediate parent class (superclass); `this` refers to the current object instance.
  • ⚡[TPSC PYQ 2025] In Java, `final` methods CANNOT be overridden by subclasses, and `final` classes (like String) CANNOT be inherited.
  • ⚡[TPSC PYQ 2025] Valid access modifiers in Java are `public`, `protected`, `private`, and default/package-private (`accessible` and `friend` are NOT Java access modifiers).
