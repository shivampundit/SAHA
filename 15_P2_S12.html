Part 1

HTML5 Tags, Attributes, Lists, Forms & Document Structure (Direct TPSC PYQ Focus)

10 One-Liners
  • ⚡[TPSC PYQ 2025] HTML stands for HyperText Markup Language; `<br>` is the correct empty tag for inserting a single line break (`<hr>` inserts a horizontal rule).
  • ⚡[TPSC PYQ 2025] The `<div>` tag defines a block-level division or section in an HTML document (`<span>` defines an inline container).
  • ⚡[TPSC PYQ 2025] The `<form>` tag is used to collect user input (`action` specifies target URL, `method` specifies GET or POST).
  • ⚡[TPSC PYQ 2025] The `<img>` tag (`<img src="pic.jpg" alt="desc">`) is used to embed/display an image on a webpage.
  • ⚡[TPSC PYQ 2025] Unordered (bulleted) list syntax in HTML is `<ul> <li>Item 1</li> </ul>`; Ordered (numbered) list is `<ol> <li>Item 1</li> </ol>`.
  • ⚡[TPSC PYQ 2025] The `<meta>` tag inside `<head>` provides metadata such as character encoding (`<meta charset="UTF-8">`), viewport settings, and page description.
  • ⚡[TPSC PYQ 2025] In legacy HTML, the `bgcolor` attribute (`<body bgcolor="...">`) specified page background color; in modern CSS, `background-color` is used.
  • ⚡[TPSC PYQ 2024] Pure HTML (without any client-side or server-side scripting) CAN embed external objects and auto-refresh/redirect via `<meta http-equiv="refresh" content="5;url=...">`, but CANNOT dynamically compute or display the live client system clock/time!
  • ⚡HTML5 Semantic Elements: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`; HTML5 Graphics: `<canvas>` (raster pixel bitmap drawn via JS) vs `<svg>` (scalable XML vector DOM elements).
  • ⚡HTML5 Web Storage: `localStorage` persists data across browser sessions with no expiration (~5–10 MB); `sessionStorage` is cleared as soon as the browser tab is closed.
Part 2

CSS3 Selectors, Styling, Box Model & Responsive Design (Direct TPSC PYQ Focus)

6 One-Liners
  • ⚡[TPSC PYQ 2025] CSS (Cascading Style Sheets) is the language used to apply visual styles and layouts to HTML elements.
  • ⚡[TPSC PYQ 2025] The `<style>` tag inside `<head>` defines an internal style sheet; `<link rel="stylesheet" href="style.css">` links an external CSS file.
  • ⚡[TPSC PYQ 2025] In CSS, the element/type selector `p {}` selects all `<p>` paragraph elements; `.className {}` selects by class attribute; `#idName {}` selects by unique ID.
  • ⚡CSS Specificity Hierarchy (Highest to Lowest): `!important` > Inline `style="..."` (1,0,0,0) > `#id` selector (0,1,0,0) > `.class` / `[attr]` / `:pseudo-class` (0,0,1,0) > Element/`::pseudo-element` (0,0,0,1).
  • ⚡CSS Box Model (Innermost to Outermost): Content -> Padding -> Border -> Margin; setting `box-sizing: border-box;` includes padding and border inside the declared `width` and `height`.
  • ⚡CSS Combinators: `div p` (all descendant `<p>` inside `div`), `div > p` (direct child `<p>` only), `div + p` (immediately adjacent sibling), `div ~ p` (all following siblings).
Part 3

JavaScript, DOM, URLs, HTTP, XML, MVC & Web Services (Direct TPSC PYQ Focus)

11 One-Liners
  • ⚡[TPSC PYQ 2025] JavaScript is the standard Client-Side scripting language executed in the browser (whereas PHP, Python, Ruby, Java, and C# are primarily Server-Side languages, though Node.js runs JS on servers).
  • ⚡[TPSC PYQ 2025] Correct HTML syntax to include an external JavaScript file is `<script src="script.js"></script>` (never `href`, `ref`, or `file`).
  • ⚡[TPSC PYQ 2025] In JavaScript, `console.log("Hello, World!")` outputs text to the browser developer console (`alert()` shows a popup dialog; `document.write()` writes to the page).
  • ⚡[TPSC PYQ 2025] DOM (Document Object Model) is a tree-structured programming interface that represents the HTML/XML page as nodes and objects so JavaScript can dynamically read and manipulate its structure, style, and content.
  • ⚡[TPSC PYQ 2025] URL stands for Uniform Resource Locator (specifies the scheme/protocol, hostname, port, path, query string, and fragment of a web resource).
  • ⚡[TPSC PYQ 2024 & 2025] HTTP stands for Hypertext Transfer Protocol; HTTP runs over TCP (Port 80), can pass parameters in a URL query string, and `HEAD` checks link validity, but HTTP does NOT describe the structure of web pages (HTML describes page structure!).
  • ⚡HTTP Methods: `GET` (safe & idempotent read), `HEAD` (safe & idempotent headers only), `PUT` (idempotent full replacement), `DELETE` (idempotent removal), `POST` (NOT idempotent — creates resource).
  • ⚡HTTP Status Codes: `1xx` Informational, `200 OK`, `201 Created`, `301 Moved Permanently`, `304 Not Modified`, `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`, `500 Internal Server Error`, `502 Bad Gateway`, `503 Service Unavailable`.
  • ⚡XML (eXtensible Markup Language) stores and transports structured data using custom case-sensitive tags; validated against a DTD (Document Type Definition) or XSD (XML Schema Definition — supports data types and XML syntax).
  • ⚡MVC (Model-View-Controller) Architecture separates an application into Model (data & business logic), View (UI presentation), and Controller (handles user input and coordinates Model & View).
  • ⚡Forward Proxy sits in front of clients to filter/anonymize outbound traffic; Reverse Proxy (Nginx, Cloudflare, HAProxy) sits in front of backend web servers for load balancing, TLS termination, and caching.
