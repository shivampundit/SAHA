Part 1

Random Signals, Autocorrelation, PSD & White Noise

6 One-Liners
  • ⚡A random process X(t) is Wide-Sense Stationary (WSS) if its mean E[X(t)] = μ is constant and its autocorrelation R_X(τ) = E[X(t)X(t+τ)] depends only on time lag τ.
  • ⚡Autocorrelation at zero lag R_X(0) = E[X²(t)] equals the TOTAL AVERAGE POWER of the random process.
  • ⚡Autocorrelation is an even function: R_X(-τ) = R_X(τ), and reaches its maximum magnitude at τ = 0 (|R_X(τ)| ≤ R_X(0)).
  • ⚡Wiener-Khinchin Theorem: Power Spectral Density (PSD) S_X(f) and Autocorrelation R_X(τ) are a Fourier Transform pair.
  • ⚡LTI System Filtering of Random Signals: If input with PSD S_X(f) passes through LTI filter H(f), output PSD is S_Y(f) = |H(f)|² · S_X(f).
  • ⚡White Noise has a flat (constant) Power Spectral Density S_n(f) = N_0 / 2 across all frequencies, and its autocorrelation is an impulse R_n(τ) = (N_0 / 2) δ(τ).
Part 2

Amplitude & Angle Modulation (AM, FM, PM) & Superheterodyne Receiver

9 One-Liners
  • ⚡Standard AM Total Power: P_t = P_c (1 + μ² / 2), where P_c is carrier power and μ is modulation index (for 100% modulation μ = 1, P_t = 1.5 P_c, efficiency η = 33.33%).
  • ⚡Transmission Bandwidth: Standard AM and DSB-SC require BW = 2 f_m; SSB-SC requires BW = f_m (saves 50% bandwidth and carrier power); VSB is used for analog TV video.
  • ⚡AM Demodulation: Envelope Detector is used for standard AM (when μ ≤ 1); Coherent (Synchronous) Detector is required for DSB-SC and SSB-SC (suffers from Costas-loop/quadrature null effect).
  • ⚡Angle Modulation: In FM, instantaneous frequency deviation Δf = k_f |m(t)|max is proportional to message amplitude; modulation index β = Δf / f_m.
  • ⚡Carson's Rule for FM Bandwidth: BW_FM = 2(Δf + f_m) = 2 f_m (β + 1); Narrowband FM (β << 1) has BW ≈ 2 f_m.
  • ⚡In FM, total transmitted power P_c = A_c² / 2 remains CONSTANT regardless of modulation index β!
  • ⚡Pre-emphasis (HPF at transmitter) and De-emphasis (LPF at receiver) boost and attenuate high-frequency audio components in FM to improve output SNR.
  • ⚡Superheterodyne Receiver mixes incoming RF signal f_RF with local oscillator f_LO to produce fixed Intermediate Frequency f_IF = |f_LO - f_RF| (455 kHz for AM, 10.7 MHz for FM).
  • ⚡Image Frequency in Superheterodyne Receiver is f_image = f_RF + 2 f_IF, which must be rejected by the front-end RF stage BEFORE the mixer.
Part 3

Information Theory, Sampling, PCM, DPCM & Delta Modulation

9 One-Liners
  • ⚡Shannon Entropy of a discrete source X: H(X) = -Σ p_i log_2(p_i) bits/symbol; Entropy is maximum (log_2 M bits) when all M symbols are equiprobable.
  • ⚡Mutual Information: I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) ≥ 0 (equals 0 when X and Y are independent).
  • ⚡Shannon-Hartley Channel Capacity Theorem (AWGN channel): C = B log_2(1 + S/N) bits/sec; absolute Shannon limit for infinite bandwidth is E_b / N_0 = ln(2) = 0.693 (-1.59 dB).
  • ⚡Nyquist Maximum Bit Rate for noiseless channel of bandwidth B with M levels: R_b = 2 B log_2(M) bps.
  • ⚡Nyquist Sampling Theorem: A bandlimited signal of max frequency f_m is completely reconstructed if sampled at f_s ≥ 2 f_m (Nyquist rate = 2 f_m); f_s < 2 f_m causes Aliasing (cured by anti-aliasing LPF).
  • ⚡PCM (Pulse Code Modulation) Pipeline: Sampling -> Quantization (non-linear irreversible step introducing quantization noise) -> Binary Encoding.
  • ⚡PCM Bit Rate & SQNR: With n bits/sample (L = 2^n levels), bit rate R_b = n · f_s bps, minimum transmission bandwidth BW_min = R_b / 2, and SQNR = (6.02 n + 1.76) dB (+6 dB per bit).
  • ⚡Companding (A-Law in Europe/India, μ-Law in USA/Japan) applies logarithmic compression before uniform quantization to improve SQNR for weak voice signals.
  • ⚡DPCM encodes prediction error to reduce bit rate; Delta Modulation (DM) is a 1-bit DPCM using a staircase approximation (suffers from Slope Overload Distortion and Granular Noise).
Part 4

Digital Modulation (ASK/PSK/FSK/QAM), Matched Filter, Hamming Codes & Multiplexing

8 One-Liners
  • ⚡[TPSC PYQ 2024] In Manchester Encoding (used in classic 10Base-T Ethernet), there is a transition in the middle of every bit period, so Bit Rate = Half of Baud Rate (or Baud Rate = 2 × Bit Rate, 50% efficiency).
  • ⚡[TPSC PYQ 2024] In RS-232 asynchronous serial communication, the Start Bit synchronizes the receiver clock for receiving every individual byte (frame).
  • ⚡BPSK transmits 1 bit/symbol with BW = 2 R_b and lowest BER = (1/2) erfc(√(E_b / N_0)); QPSK transmits 2 bits/symbol with BW = R_b (half the bandwidth of BPSK for the same BER!).
  • ⚡Matched Filter Receiver has impulse response h(t) = s(T - t) (time-reversed, delayed copy of signal) and maximizes output peak SNR = 2E / N_0 in AWGN.
  • ⚡MAP (Maximum A Posteriori) Detector minimizes overall error probability; ML (Maximum Likelihood) Detector equals MAP when all symbols have equal prior probabilities.
  • ⚡Hamming Distance d_min: To detect up to s bit errors, d_min ≥ s + 1; to correct up to t bit errors, d_min ≥ 2t + 1; Hamming inequality for (n,k) single-error correcting code is 2^(n-k) ≥ n + 1.
  • ⚡Inter-Symbol Interference (ISI) is caused by channel dispersion; eliminated by Nyquist Raised-Cosine Pulse Shaping (BW = (R_s / 2)(1 + α), where α is roll-off factor) and Equalizers.
  • ⚡Multiple Access: FDMA splits frequency bands (needs guard bands); TDMA splits time slots (needs guard times); CDMA assigns orthogonal Walsh/PN codes so all users share full frequency and time simultaneously.
