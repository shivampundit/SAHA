Part 1

Algorithm Fundamentals & Asymptotic Complexity (Direct TPSC PYQ Focus)

10 One-Liners
  • ⚡[TPSC PYQ 2025] An Algorithm is a finite, well-defined step-by-step set of instructions to solve a problem or perform a task.
  • ⚡[TPSC PYQ 2025] Characteristics of a good algorithm: Input, Output, Finiteness, Definiteness/Precision, and Effectiveness ('Ambiguity' is NOT a characteristic of a good algorithm!).
  • ⚡[TPSC PYQ 2025] Time complexity of an algorithm is determined by counting the number of elementary operations executed as a function of input size n.
  • ⚡[TPSC PYQ 2025] Big-O notation O(g(n)) describes the Asymptotic Upper Bound (worst-case growth rate) of an algorithm's time or space complexity.
  • ⚡Big-Omega Ω(g(n)) describes the Asymptotic Lower Bound (best case); Theta Θ(g(n)) describes the Asymptotic Tight Bound (when O and Ω coincide).
  • ⚡[TPSC PYQ 2024] Loop `for(i=n; i>0; i/=2) for(j=0; j<i; j++) count++;` executes n + n/2 + n/4 + ... + 1 = 2n - 1 times, so its time complexity is O(n)!
  • ⚡[TPSC PYQ 2025] In Discrete Mathematics, a Relation between sets A and B is a subset of the Cartesian product A × B, i.e., a Set of Ordered Pairs.
  • ⚡[TPSC PYQ 2025] Principle of Inclusion-Exclusion |A ∪ B| = |A| + |B| - |A ∩ B| is used for finding the size (cardinality) of the union of sets.
  • ⚡[TPSC PYQ 2025] Valid discrete graph representations/types include Tree, Directed Acyclic Graph (DAG), and Complete Graph ('Continuous graph' is NOT a valid discrete math graph).
  • ⚡Asymptotic Growth Order (Smallest to Largest): O(1) < O(log log n) < O(log n) < O(√n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2^n) < O(n!) < O(n^n).
Part 2

Searching, Sorting & Hashing Algorithms (Direct TPSC PYQ Focus)

11 One-Liners
  • ⚡[TPSC PYQ 2025] For an UNSORTED array, Linear Search is the only applicable general search and has worst-case and best-guaranteed time complexity O(n) (best case O(1)).
  • ⚡Binary Search requires a SORTED array with random access and runs in O(log n) worst/average time and O(1) iterative space: T(n) = T(n/2) + O(1).
  • ⚡[TPSC PYQ 2025] Quick Sort and Merge Sort are classic examples of the Divide-and-Conquer algorithm design paradigm.
  • ⚡[TPSC PYQ 2025] Merge Sort has Worst-Case, Average-Case, and Best-Case time complexity of O(n log n), and requires O(n) auxiliary space (it is Stable, NOT in-place).
  • ⚡[TPSC PYQ 2025] Quick Sort has Best-Case and Average-Case time complexity O(n log n), but Worst-Case O(n²) (when array is already sorted/reverse-sorted and pivot is extreme; uses O(log n) stack space).
  • ⚡Bubble Sort and Insertion Sort have Best-Case time O(n) (when array is already sorted!) and Worst/Average-Case O(n²); both are Stable and In-Place.
  • ⚡Selection Sort ALWAYS takes Θ(n²) comparisons in Best, Average, and Worst cases, but performs at most O(n) swaps (minimum swaps among comparison sorts).
  • ⚡Heap Sort runs in O(n log n) time in ALL cases (Best, Average, Worst) with O(1) auxiliary space (In-place, but NOT stable).
  • ⚡Decision-Tree Lower Bound: Any comparison-based sorting algorithm requires at least Ω(n log n) comparisons in the worst case.
  • ⚡Non-Comparison Sorts: Counting Sort runs in O(n + k) and Radix Sort in O(d(n + k)) (both are Stable and beat Ω(n log n) when range k is small).
  • ⚡Hashing provides O(1) average search/insert/delete, and O(n) worst case (when all keys collide); Open Addressing uses Linear Probing (primary clustering), Quadratic Probing (secondary clustering), or Double Hashing.
Part 3

Greedy, Dynamic Programming & Graph Algorithms (Direct TPSC PYQ Focus)

8 One-Liners
  • ⚡[TPSC PYQ 2025] Prim's Algorithm, Kruskal's Algorithm, Dijkstra's Algorithm, Huffman Coding, and Fractional Knapsack are Greedy Algorithms.
  • ⚡[TPSC PYQ 2024] Computing the Transitive Closure of a binary relation on n elements using Warshall's algorithm takes O(n³) time.
  • ⚡Greedy vs Dynamic Programming: Fractional Knapsack is solved optimally by Greedy in O(n log n), whereas 0/1 Knapsack requires Dynamic Programming in O(nW) (pseudo-polynomial).
  • ⚡Minimum Spanning Tree (MST): Connects all V vertices of a connected undirected weighted graph with V - 1 edges and minimum total weight (Prim's works best on dense graphs O(V²); Kruskal's on sparse graphs O(E log E) using Disjoint-Set Union-Find).
  • ⚡Cycle Property & Cut Property of MST: If all edge weights in a graph are distinct, the Minimum Spanning Tree is guaranteed to be UNIQUE.
  • ⚡Single-Source Shortest Path: Dijkstra's Algorithm (Greedy, requires non-negative edge weights, O((V+E) log V)); Bellman-Ford Algorithm (Dynamic Programming, handles negative weights and detects negative cycles in O(VE)).
  • ⚡All-Pairs Shortest Path: Floyd-Warshall Algorithm uses Dynamic Programming in Θ(V³) time and Θ(V²) space.
  • ⚡Graph Traversals: Breadth-First Search (BFS) uses a Queue in O(V + E) and finds shortest paths in unweighted graphs; Depth-First Search (DFS) uses a Stack/Recursion in O(V + E) and is used for Topological Sorting of a DAG and cycle detection.
