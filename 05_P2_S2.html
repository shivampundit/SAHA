Part 1

Number Systems, Base Conversions & Signed/Floating-Point Arithmetic (TPSC PYQ Focus)

10 One-Liners
  • ⚡[TPSC PYQ 2024] (1.3125)_10 in base 16 (Hexadecimal) is 1.5, because 0.3125 × 16 = 5.0.
  • ⚡[TPSC PYQ 2024] Decimal 13 in binary is 1101 (8 + 4 + 0 + 1 = 13).
  • ⚡[TPSC PYQ 2024] In 16-bit 2's complement, multiplying P = (F87B)_16 by 8 equals a left arithmetic shift by 3 bits, giving (C3D8)_16.
  • ⚡[TPSC PYQ 2024] In IEEE 754 single-precision (32-bit: 1 sign, 8 biased exponent with bias 127, 23 fraction), decimal 0.5 = 1.0 × 2^(-1) has fraction bits 000...000 and true exponent -1 (biased exponent 126).
  • ⚡Range of n-bit Signed Representations: Sign-Magnitude and 1's Complement = -(2^(n-1) - 1) to +(2^(n-1) - 1) (two zeros: +0 and -0); 2's Complement = -2^(n-1) to +(2^(n-1) - 1) (unique zero).
  • ⚡Range of 8-bit 2's Complement Integer is -128 to +127; Range of 16-bit 2's Complement Integer is -32,768 to +32,767.
  • ⚡2's Complement Overflow Condition: Overflow occurs iff Carry-into-MSB (C_{n-1}) XOR Carry-out-of-MSB (C_n) = 1 (adding two positives gives negative, or two negatives gives positive).
  • ⚡Sign Extension in 2's Complement: Replicate the MSB (sign bit) into all newly added left positions.
  • ⚡BCD (8421) Code uses 4 bits per decimal digit (0000 to 1001; 1010–1111 are invalid; add 0110 = 6 on invalid sum or carry); Excess-3 (XS-3) and 2421 are Self-Complementing codes.
  • ⚡Gray Code is a unit-distance unweighted code where consecutive numbers differ by only 1 bit (minimizes switching errors in rotary encoders and K-maps): G_msb = B_msb, G_i = B_{i+1} ⊕ B_i.
Part 2

Boolean Algebra, Logic Gates & K-Map Minimization (TPSC PYQ Focus)

10 One-Liners
  • ⚡[TPSC PYQ 2025] XNOR gate (Equivalence gate, A ⊙ B = AB + A'B') outputs '1' ONLY when both inputs are the same (0,0 or 1,1).
  • ⚡[TPSC PYQ 2025] XOR gate (Inequality / Odd-1s detector, A ⊕ B = A'B + AB') outputs '1' when inputs are different.
  • ⚡[TPSC PYQ 2025] Boolean expression for AND gate is A · B; OR gate outputs '1' if at least one input is 1 (A + B).
  • ⚡[TPSC PYQ 2025] NAND and NOR are Universal Gates because any Boolean function can be realized using only NAND or only NOR gates.
  • ⚡Minimum Universal Gates needed for basic gates: NOT = 1 NAND / 1 NOR; AND = 2 NAND / 3 NOR; OR = 3 NAND / 2 NOR; XOR = 4 NAND / 5 NOR; XNOR = 5 NAND / 4 NOR.
  • ⚡De Morgan's Laws: (A · B)' = A' + B' (NAND = Bubbled OR) and (A + B)' = A' · B' (NOR = Bubbled AND).
  • ⚡Absorption Laws: A + AB = A; A(A + B) = A; A + A'B = A + B; A(A' + B) = AB.
  • ⚡Consensus Theorem: AB + A'C + BC = AB + A'C (the redundant consensus term BC is eliminated); Dual: (A+B)(A'+C)(B+C) = (A+B)(A'+C).
  • ⚡For n Boolean variables, there are 2^n minterms/maxterms and 2^(2^n) possible Boolean functions (for n=2, 16 functions; for n=3, 256 functions).
  • ⚡K-Map Grouping Rules: Groups must have size 2^k (1, 2, 4, 8, 16); a group of 2^k adjacent 1s eliminates k variables and leaves (n - k) literals.
Part 3

Combinational Circuits (Adders, MUX, Decoders, Encoders)

7 One-Liners
  • ⚡[TPSC PYQ 2025] Full Adder Sum output is S = A ⊕ B ⊕ C_in, and Carry output is C_out = AB + BC_in + AC_in = AB + C_in(A ⊕ B).
  • ⚡Half Adder adds 2 bits: Sum = A ⊕ B, Carry = A · B (requires 5 NAND gates or 5 NOR gates); a Full Adder is built from 2 Half Adders + 1 OR gate (9 NAND gates).
  • ⚡Half Subtractor: Difference = A ⊕ B, Borrow = A'B; Full Subtractor Borrow = A'B + A'B_in + BB_in.
  • ⚡Carry Look-Ahead (CLA) Adder eliminates ripple carry propagation delay using Generate G_i = A_i B_i and Propagate P_i = A_i ⊕ B_i, where C_{i+1} = G_i + P_i C_i.
  • ⚡A 2^n : 1 Multiplexer (Data Selector) has 2^n data inputs, n select lines, and 1 output; a 2:1 MUX is a universal logic module.
  • ⚡Number of 2:1 MUXes required to build a 2^n : 1 MUX is (2^n - 1) (e.g., 16:1 MUX needs 15 of 2:1 MUXes).
  • ⚡An n-to-2^n Decoder with OR gates can implement any Boolean function by summing its minterms; an Encoder performs the inverse operation (Priority Encoder resolves multiple simultaneous active inputs).
Part 4

Sequential Circuits (Flip-Flops, Counters & Shift Registers)

8 One-Liners
  • ⚡Latches are level-triggered (transparent when enable is high), whereas Flip-Flops are edge-triggered (sampled at rising or falling clock edge).
  • ⚡SR Flip-Flop: S=0, R=0 (Hold Q_n); S=0, R=1 (Reset 0); S=1, R=0 (Set 1); S=1, R=1 is the Invalid / Forbidden state (Q_{n+1} = S + R'Q_n with SR = 0).
  • ⚡JK Flip-Flop eliminates the SR invalid state: J=1, K=1 toggles the output (Q_{n+1} = Q_n'); characteristic equation is Q_{n+1} = JQ_n' + K'Q_n.
  • ⚡Race-Around Condition occurs in a level-triggered JK Latch when J=K=1 and clock pulse width t_p > propagation delay t_pd; cured by Master-Slave JK Flip-Flop or edge triggering.
  • ⚡D Flip-Flop (Delay / Data FF): Q_{n+1} = D; T Flip-Flop (Toggle FF): Q_{n+1} = T ⊕ Q_n (when T=1, it divides clock frequency by 2: f_out = f_clk / 2).
  • ⚡A MOD-N counter has N distinct states, divides input clock frequency by N (f_out = f_in / N), and requires n = ⌈log_2 N⌉ flip-flops (e.g., MOD-10 Decade/BCD counter requires 4 flip-flops).
  • ⚡n-bit Ring Counter has N = n states; n-bit Johnson (Twisted Ring / Mobius) Counter has N = 2n states.
  • ⚡Shift Register Types: SISO (requires n clocks to load, n-1 to read), SIPO (n clocks), PISO (1 clock load, n-1 shift), PIPO (1 clock); left-shift by 1 multiplies by 2, right-shift divides by 2.
